SIMBOLOS BASICOS:
#       → Título
##      → Subtítulo
** **   → Negrita
* *     → Cursiva
*** *** → Negrita + cursiva
~~ ~~   → Tachado
` `     → Código en línea
>       → Cita
-       → Lista
1.      → Lista numerada
- [ ]   → Checkbox
- [x]   → Checkbox terminado
---     → Separador
[ ]( )  → Link
![ ]( ) → Imagen
